# PT Trimiz Sinergy Mandala (TSM) - Official Landing Page

Website profil perusahaan dan katalog beton ready mix untuk **PT Trimiz Sinergy Mandala (TSM)** yang beroperasi di Garut, Jawa Barat sejak tahun 2011.

## 🌟 Fitur Utama
- **Profil Perusahaan & Sejarah**: Informasi legalitas, visi misi (3T: Tepat Jumlah, Tepat Mutu, Tepat Waktu), dan pengalaman proyek Bendungan Copong Garut.
- **Katalog Armada & Fasilitas**:
  - 11 Unit Truk Molen Standar (5 m³)
  - 4 Unit Truk Mini Mix (3 m³) spesialis jalan gang sempit (P: 5m, L: 2m, T: 3m)
  - 1 Unit Concrete Pump lengan robotik (boom)
  - Twin Silo Batching Plant di Jl. Sudirman No. 19 Copong, Garut
- **Laboratorium Uji Mutu Beton**: Standar acuan Fc' silinder (SNI/ACI) & karakteristik kubus 15x15x15 cm (K-175 s/d K-500).
- **Kalkulator Kebutuhan Beton Interaktif**: Simulasi volume cor dak, jalan, kolom, atau pondasi beserta estimasi jumlah rit truk molen standar dan mini mix.
- **Order WhatsApp Otomatis**: Form pemesanan terintegrasi langsung ke WhatsApp Hotline resmi `0821-1693-8147`.
- **Desain Modern Light Theme & Mobile-First**: Tampilan putih bersih, responsif, dan mudah diakses di smartphone.

## 📁 Struktur Direktori
- `index.html` : Halaman utama website
- `style.css` : Stylesheet Vanilla CSS responsif
- `script.js` : Logika kalkulator beton, navigasi mobile, filter tab, dan WhatsApp generator
- `assets/img/` : Aset logo resmi TSM dan foto dokumentasi operasional lapangan

## 🚀 Penggunaan Langsung
Buka file `index.html` di browser apa pun atau jalankan server lokal:
```bash
python -m http.server 8080
```
Lalu akses `http://localhost:8080/`.
